# Private provider link test gate

The known Project Lumen provider URL is not stored in source control. Device acceptance must verify the previously supplied link without exposing credentials in logs or screenshots.

Required checks: complete download, 100,000-entry ceiling, encrypted persistence, restart restore, dynamic languages, Live/Movies/Series separation, logos, Media3 playback, audio track selection, Back-to-Picture-in-Picture on smartphone, and D-pad navigation on Fire TV.
